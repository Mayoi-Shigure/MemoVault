# MemoVault UI / UX 与 Landing Page 人工验收

使用本地或独立测试账户，不使用生产私人资料。以下项目需要人工确认；自动检查不能替代真实浏览器体验。

## 路由与数据边界

- [ ] 无痕窗口打开 `/`：显示公开介绍、示例预览和 EN / 中文，不出现账户、私人记录或真实统计。
- [ ] 顶部、Hero、页尾 Get started 均到 `/register`；Sign in 到 `/login`。
- [ ] 注册成功后显示成功状态，仍未自动登录；登录后返回 `/` 的 Dashboard。
- [ ] 已登录刷新 `/`、点击品牌/Home 都正常进入 Dashboard，旧链接继续可用。
- [ ] 未登录直接访问 `/notes`、记录详情、编辑页均跳转登录。
- [ ] 退出确认取消不退出；确认后回到登录页，随后 `/` 显示 Landing，受保护页面不可访问。

## Landing Page

- [ ] 1440、1024、768、375px 宽度逐一检查；Hero 自然堆叠，按钮不截断，预览和页尾无横向溢出。
- [ ] EN / 中文分别检查标题换行、导航、Save / Organize / Find 与 CTA。
- [ ] 预览清楚标为示例，没有可误认为真实操作的按钮，没有未实现功能宣传。
- [ ] 系统开启“减少动态效果”，预览无进入动画，导航/CTA 仍正常。

## Dashboard / Library

- [ ] 有记录时显示最近更新、真实 Type、摘要和时间；空账户显示新增入口，无假统计。
- [ ] Library 标题、Type、摘要、URL、更新时间便于扫描；鼠标悬停及键盘聚焦有反馈。
- [ ] 搜索标题/内容，检查搜索词展示与无结果提示；清除筛选回完整 Library。
- [ ] 按 Type、Ungrouped 浏览，检查页头筛选状态、空类型提示与新增入口。
- [ ] 保持原搜索语义：有搜索词时全库搜索，不宣称和 Type 联合筛选。
- [ ] 用超长中文/英文标题、无空格长标题、长 Type、长 URL 检查截断与布局；详情页完整阅读。
- [ ] 来源链接仍打开新标签；记录标题进入详情。

## Record / 表单 / Modal

- [ ] Add：标题必填，可选内容/URL、类型选择正常；保存、取消、校验错误行为符合原功能。
- [ ] Detail：标题/来源/内容/时间完整可读，换行保留，空内容有提示。
- [ ] Edit：Title、Type、Content、URL 标签明确，保存与取消正确返回。
- [ ] Delete 按钮视觉次要；打开确认默认聚焦取消，取消/Escape/遮罩关闭不删除；确认删除正常。
- [ ] New Type / Rename：初始聚焦输入框，错误清晰，保留输入值。
- [ ] 弹窗打开时 Tab / Shift+Tab 不进入背景；关闭后返回可见触发按钮。
- [ ] Add 的 `#add-record` 入口以及后端校验失败自动打开弹窗正常。
- [ ] 375px 和短屏/手机软键盘下，弹窗可滚动，字段和底部按钮可到达。
- [ ] 快速重复打开/关闭弹窗，动画不阻塞操作，也不残留背景禁用状态。

## Type / Sidebar

- [ ] 创建、重命名自定义 Type；未使用 Type 可删除。
- [ ] 默认 Type 没有重命名/删除操作；仍被记录使用的 Type 删除失败时显示原错误。
- [ ] 展开/折叠箭头、子记录缩进、当前记录与当前 Type 状态清楚。
- [ ] 刷新保留折叠状态（`memovault-sidebar-collapsed`）。
- [ ] Type 搜索、隐藏空类型正常；筛选不改变原折叠状态。
- [ ] 刷新保留隐藏空类型（`memovault-hide-empty-types`）和侧栏滚动位置（`memovault-sidebar-scroll`）。
- [ ] 长 Type、记录标题、账户名不挤坏侧栏；超长名称可在详情或悬停提示中查看。
- [ ] 768/375px 点击 Types 展开类型树，可搜索、折叠和导航；Escape 收起并回到按钮。
- [ ] Account 菜单不挤动底部布局；打开/关闭/窗口缩放正常。
- [ ] Account 按 Enter、方向键、Tab、Escape 可操作；退出确认取消后焦点恢复正确。
- [ ] Type 操作菜单 Escape 返回更多按钮；重命名/删除弹窗关闭后焦点返回更多按钮。

## 全站语言、键盘与响应式

- [ ] Landing / Login / Register / Dashboard / Library / Detail / Edit 均检查 1440、1024、768、375px。
- [ ] EN / 中文在页面间、刷新后保留；用户创建的 Type、Title、Content、URL 不翻译。
- [ ] 所有可交互控件可通过 Tab 到达，焦点轮廓清楚；禁用状态与普通状态可区分。
- [ ] Login 错误、Register 错误和成功清楚，密码不回填。
- [ ] 系统减少动态效果时，按钮/弹窗/菜单/折叠仍可用且无非必要动画。
- [ ] 用实际手机 Safari / Chrome 检查软键盘、触摸目标、短屏滚动和文本缩放（200%）。
- [ ] 屏幕阅读器抽查表单标签、语言按钮选中状态、展开状态、错误提示及 Modal 标题。
